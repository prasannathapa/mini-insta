Setup & tooling

Everything you need to build, test and run Mini Instagram, and what each tool is for. The only thing you must install yourself is a JDK.

1. JDK (Java Development Kit)

What it is. The JDK is the compiler (javac) plus the runtime (java) and the standard library. The JRE (runtime) alone can run Java; the JDK can also compile it, which is what we need.

Why 25. We use Java 25 language features (records, sealed classes, pattern-matching switch, text blocks). 25 is a Long-Term-Support release. The project was built with JDK 26 targeting the 25 language level, so any JDK 25 or newer works.

How to install.

  • Download a build from Adoptium (Temurin), Amazon Corretto, or Oracle. Pick JDK 25 (or newer), your OS, the .msi/.pkg installer.
  • Verify: `` java -version ` You should see 25 or higher. If it shows an older version, set JAVA_HOME` to the new JDK (below).

Setting JAVA_HOME (only if your default java is too old):

  • Windows (PowerShell, current session): setx JAVA_HOME "C:\path\to\jdk-25" then reopen the terminal.
  • macOS/Linux (bash/zsh): export JAVA_HOME=/path/to/jdk-25 in your shell rc.

The build scripts and the Maven wrapper use JAVA_HOME if set, otherwise the java on your PATH.

2. Maven (via the wrapper - no install needed)

What it is. Maven is a build tool and dependency manager. It compiles the code, runs the tests, downloads libraries (our SQLite driver and JUnit), and packages a runnable .jar - all described by one file, pom.xml.

Why. Doing this by hand (javac with a long classpath, manually downloading jars) is error-prone. Maven makes the build reproducible on any machine.

Why you don't install it. The repo ships the Maven Wrapper (mvnw, mvnw.cmd, .mvn/wrapper/). The first time you run it, it downloads the exact Maven version this project expects and caches it. So you only need a JDK.

3. JUnit 5 (tests)

What it is. JUnit is the testing framework. A test is a method annotated @Test that asserts something about the code (assertEquals, assertTrue, ...).

Why. The tests are executable documentation and a safety net: mvnw test fails the build the moment behaviour breaks. Each step-NN checkpoint keeps its tests green.

How to use it. You don't install it - Maven pulls it in (see pom.xml, junit-jupiter). Run mvnw test. Test sources live under src/test/java.

4. SQLite (database)

What it is. SQLite is a small SQL database that lives in a single file (or in memory) with no server to run. We reach it through JDBC (Java's standard database API) using the sqlite-jdbc driver, which Maven downloads.

Why here. It makes persistence, tables, foreign keys, indexes and normalization real and runnable without any setup. See ARCHITECTURE.html and HLD.html for how it fits and its limits.

How to use it. Nothing to install - the driver is a dependency. Run the app with -Dmini.store=sqlite to use it; a database file appears under data/. The schema is in src/main/resources/schema.sql. Optionally install the sqlite3 CLI to inspect that file by hand.

5. Opening the project in an IDE

IntelliJ IDEA: File -> Open the project folder (or pom.xml). It reads the Maven project, downloads dependencies and indexes everything. Set the project SDK to JDK 25+ (File -> Project Structure -> Project).

VS Code: install the Extension Pack for Java, then open the folder.
